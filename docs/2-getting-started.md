This chapter provides the information required to install and start using OsdagBridge. It covers system requirements, installation, application launch, and the prerequisites for beginning a bridge analysis and design.

### 2.1 System Requirements

OsdagBridge is currently supported on *Windows* and *Linux* operating systems.

:::note
OsdagBridge is not currently supported on *macOS*.
:::

Before installing OsdagBridge, ensure that the system meets the required operating system and software prerequisites.

### 2.2 Installation and Setup

OsdagBridge can be installed using the *single-click download* provided on the OsdagBridge website.

Download the appropriate installer for the supported operating system and follow the installation instructions provided with the application.

For detailed installation instructions, refer to the *Download* section of the OsdagBridge website.

### 2.3 Launching OsdagBridge

After installation, launch OsdagBridge using the *OsdagBridge desktop icon* created during installation.

Double-click the desktop icon to start the application.

Once launched, OsdagBridge opens to the *Home Screen*, which provides access to the available project configuration, input, analysis, and design functions.

### 2.4 Initial Setup

On the first launch, verify that the application starts correctly and that the required components are available.

No additional configuration is required unless specified by the selected project or design workflow.

### 2.5 Basic Prerequisites

Before beginning a bridge analysis and design, ensure that the required project information is available, including:

- Project and site information
- Bridge geometry and dimensional parameters
- Structural and material properties
- Loading information
- Applicable design requirements

The required inputs may vary depending on the selected project configuration and design module.
